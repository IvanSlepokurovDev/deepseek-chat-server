# DeepSeek Chat Server

HTTP-сервер на Kotlin + Ktor: проксирует диалог в DeepSeek API, храня историю сообщений в памяти.

- Порт: `8080`
- Эндпоинт: `POST /chat` — принимает JSON `{"prompt": "..."}`, возвращает `{"reply": "..."}`
- Системный промпт захардкожен: «Ты — полезный ассистент»
- При каждом запросе в DeepSeek отправляется вся история диалога (системный промпт + предыдущие сообщения + новый запрос)
- История хранится в памяти и сбрасывается при перезапуске сервера
- Модель: `deepseek-flash`, `thinking` включён, `reasoning_effort: high`

## Требования

- JDK 21+

## Запуск

1. Положите ключ API в файл `local.conf` в корне проекта (файл в git не попадает — он в `.gitignore`):

```hocon
deepseek {
  apiKey = "sk-..."
}
```

2. Запустите сервер:

```bash
./gradlew run
```

Приоритет настроек: `local.conf` → переменная окружения `DEEPSEEK_API_KEY` (fallback) → `application.conf` из ресурсов.

## Пример запроса

```bash
curl -X POST http://localhost:8080/chat \
  -H 'Content-Type: application/json' \
  -d '{"prompt": "Привет! Кто ты?"}'
```

Ответ:

```json
{"reply": "Привет! Я — полезный ассистент..."}
```

Второй запрос к тому же серверу продолжится в контексте первого — сервер помнит историю диалога.
